## 財神爺接金幣

用瀏覽器直接打開就能玩的小遊戲，不需要安裝、建置或連網。

### 怎麼玩
1. 下載或 clone 這個 repo，直接雙擊 `index.html`（Chrome、Safari 皆可）。
2. 按「開始遊戲」，畫面播放 3、2、1 倒數動畫，3 秒後顯示「開始！」並正式開始。
3. 財神爺站在畫面上方的祥雲上左右移動、隨機撒下金幣，移動畫面最下方的竹簍把金幣接住。
4. 每場 30 秒，左上角顯示剩餘秒數、右上角顯示目前得分（接到一枚金幣 +1）。
5. 整場固定掉落 50 枚金幣，時間越久金幣掉得越快、越密集。
6. 整場還會從畫面上方掉下 10 顆石頭，竹簍接到一顆扣 5 分（最低 0 分，不會變負數），閃過不扣分。
7. 時間到會顯示「得分 X 分」，以及接到金幣幾枚（滿分 50）、打到石頭幾顆，按「再玩一次」重新開始。
8. 接到金幣會播放「叮」的音效（打到石頭沒有音效）；手機請開啟聲音，iPhone 實體靜音鍵開啟時可能聽不到。

### 操作
- 鍵盤：← → 方向鍵，或 A / D
- 滑鼠：在畫面上左右移動
- 手機：手指在畫面上拖曳
